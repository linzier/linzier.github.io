URL Shortener Service (Mingyuanyun) Architecture Design + Core Development
Provides short URL to long URL redirection, widely used in SMS and other character-limited scenarios. The core challenge was performance in short-to-long URL lookup and redirection latency. Algorithm: auto-increment ID converted to base-62. The database auto-increment primary key is converted to base-62 as the short URL identifier (using 0-9a-zA-Z, 62 characters). When resolving, convert base-62 back to decimal for direct primary key lookup, avoiding hash collisions and full table scans — simple and high-performance. Optimizations: (1) Redis Hash caches hot URL mappings to reduce DB queries; (2) Redis Bloom filter intercepts non-existent short URLs to prevent cache penetration attacks.

On AI & Vibe Coding

Vibe coding (letting AI write all the code) is gradually replacing hand-written code as the mainstream development approach. Clients often ask me the same question: With AI, can just anyone build a production system?

The answer is no. For at least the next 3 years, someone with no coding experience cannot build a production-ready system relying solely on AI.

Here are the key insights from our team's long-term practice:

  1. AI excels at features, not architecture. Building a feature is fast, but overall system architecture design heavily depends on human experience — AI cannot yet handle this.
  2. Prompt quality determines output quality. A single word difference can produce drastically different results (with vastly different token consumption). Vibe coding is equally dependent on human experience and skill.
  3. As complexity grows, AI produces more bugs than humans. Rigorous code review is indispensable.
  4. AI code often stops at "it works." It falls short on performance and maintainability compared to human-written code — and the quality of the final review depends entirely on the reviewer's ability.
  5. Hallucinations are inevitable. Even Claude Opus hallucinates, sometimes in subtle but critical places. Robust review and testing processes are the only safety net.
Conclusion: AI is an amplifier — it can multiply the efficiency of experienced developers several times over, but it cannot replace experience itself. I can help you deliver faster and better with AI while ensuring your systems run stably and at high quality in production.
